wallet-egress-lab

Wallet Egress Inventory

Each run plays a scripted user through a web wallet behind a recording proxy, then classifies every request by who receives it and what it reveals: address-free, telemetry, address-linked, or intent before chain. Each report ends with a routing plan: which calls stay on the plain path, which need the origin hidden (OHTTP relay or anon-RPC), and which need the content hidden (PIR).

Reproduce

Run it yourself

Setup, method and techniques are in the repository README. Testing another wallet means replacing the steps in driver/journey.ts.

git clone https://github.com/andyguzmaneth/wallet-egress-lab && cd wallet-egress-lab
npm install && npx playwright install chromium && uv tool install mitmproxy
scripts/run.sh sepolia     # setup, keys and the full command list are in the README
1 run.
